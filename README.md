# UKKMate

**Muhamad Khoirul Ramadhan (2413025012)**

Aplikasi Pendukung Uji Kompetensi Keahlian (UKK) Siswa SMK berbasis Flutter dengan arsitektur Offline-First.

## Fitur Utama
- **Dashboard Siswa**: Monitoring progres capaian kompetensi UKK & jadwal simulasi.
- **Latihan Mandiri & Simulasi CBT**: Bank soal interaktif, pembahasan kunci jawaban, dan offline-ready caching.
- **Portal Guru Pendamping**: Pemantauan ujian asesi langsung (Live Monitor), daftar nilai & evaluasi kompeten.
- **Status Sinkronisasi Offline-First**: Sinkronisasi otomatis ke server lokal/pusat saat online.
- **Profil Siswa & Validasi NISN**: Integrasi data akademik Dapodik dan avatar sesuai gender.
